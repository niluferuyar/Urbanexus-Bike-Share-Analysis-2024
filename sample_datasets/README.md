# Data Samples
This folder contains 50-row sample datasets derived form the original Divvy Bikes trip data used in this project.
- **'urbanexus_raw_sample.csv'**: Sampled from the original row dataset.
- **'urbanexus_cleaned_sample.csv'**: Sample extracted from cleaned and formatted dataset.
- **'urbanexus_core_sample.csv'**: Sampled from transformed, filtered and outlier-removed, analysis-ready dataset.
  
> Note: The full dataset includes over 5+ million rows and can be accessed from the [Divvy Bikes data portal](https://divvybikes.com/system-data).
